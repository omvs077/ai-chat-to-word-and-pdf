Fix ChatGPT adapter hanging indefinitely on export (findScrollContainer false positive)

Real bug found on the very first live export attempt: extraction hung at
"Extracting conversation from the page..." indefinitely (confirmed via
live diagnostics to sit well past 90 seconds with zero visible page
scrolling), never completing or erroring.

Root cause: findScrollContainer's generic "walk up until tall enough"
check (content.js's approach for Claude, reused verbatim in the original
version of this function) found <main> (confirmed live: scrollHeight 6725
vs clientHeight 858) before ever reaching the real scroll container -
<main> is naturally tall from normal page layout without itself being the
overflow:auto element that actually scrolls. Setting scrollTop on a
non-scrolling element does nothing, so the stability-wait loop spun for
its full ceiling waiting for a scrollHeight that could never change. The
same heuristic works correctly on claude.ai only because claude.ai's DOM
doesn't happen to have an intervening merely-tall non-scrolling wrapper
between a message and its real scroll container - this isn't a coding
mistake in the reuse, it's a genuine platform-specific gap in a heuristic
that was never wrong on the site it was originally built for.

Fix, in two layers:
  1. Tries a real, live-confirmed class fragment first
     ([class*="scrollport" i], matching "group/scrollport ...
     overflow-y-auto", scrollHeight 1343 vs clientHeight 844 when checked
     directly via DevTools).
  2. The walk-up fallback now also requires genuine overflow-y:auto|scroll
     on the computed style, not just a height difference - so it can no
     longer false-positive on a merely-tall non-scrolling wrapper the way
     the original height-only check did.

New regression test reconstructs the exact real shape (a tall non-
scrolling wrapper around the real scrollable region) and was confirmed,
via a real revert-and-rerun, to actually hang - not just fail an
assertion - on the original broken code, matching what was seen live.

Test suite: 38 -> 39 passing tests.
